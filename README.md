# Frigg

The open market for Omarchy. Developers publish freely, buyers pay them directly in sats.

- `site/` the store website (static, no build step)
- `apps/` one JSON manifest per app, plus `index.json` (the catalog)
- `bin/frigg` the command-line client (draft)
- `menu/` the rows that put Frigg in the Omarchy menu

Frigg is an independent project by Hasky Labs and is not affiliated with Omarchy or 37signals.
